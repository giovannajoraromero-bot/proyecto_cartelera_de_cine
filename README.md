CARTELERA DE CINE
1. Descripción del proyecto

El proyecto Cartelera de Cine consiste en el desarrollo de un programa realizado en Python que permite administrar y consultar la programación de películas de un cine.

Está inspirado en plataformas como Cine Center y tiene como propósito facilitar la organización de las películas, sus horarios y funciones, ofreciendo una experiencia sencilla para el administrador y los clientes.

2. Objetivo del proyecto

Desarrollar un programa que permita gestionar la cartelera de un cine, facilitando el registro de películas, la organización de sus funciones y la consulta de los horarios disponibles.

3. Funcionalidades principales

El sistema cuenta con diferentes opciones para organizar y consultar la información del cine.

- Registro de películas: permite añadir nuevas películas a la cartelera.
- Consulta de películas: muestra las películas disponibles y su información.
- Modificación de datos: permite actualizar la información registrada.
- Eliminación de películas: permite retirar películas de la cartelera.
- Gestión de funciones: permite organizar los horarios y las salas de cada película.
- Consulta de cartelera: permite visualizar las películas y sus respectivos horarios.

4. Herramientas utilizadas

- Python: lenguaje utilizado para desarrollar el programa.
- Visual Studio Code: programa utilizado para escribir y editar el código.
- Git: herramienta para guardar y controlar los cambios realizados.
- GitHub: plataforma utilizada para compartir el proyecto y trabajar en equipo.

5. Organización del proyecto

El programa está organizado en diferentes archivos, cada uno encargado de una parte del sistema.

CARTELERA-CINE/
│
├── main.py
├── peliculas.py
├── funciones.py
├── cartelera.py
└── README.md

- main.py: inicia el programa y muestra el menú principal.
- peliculas.py: contiene las opciones para administrar las películas.
- funciones.py: se encarga de organizar las funciones y horarios.
- cartelera.py: permite mostrar la programación del cine.
- README.md: contiene la información general del proyecto.

6. ¿Cómo utilizar el programa?

Para utilizar el sistema se deben seguir estos pasos:

1. Descargar o clonar el proyecto desde GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Verificar que Python esté instalado.
4. Ejecutar el archivo "main.py".
5. Seleccionar la opción deseada en el menú principal.
