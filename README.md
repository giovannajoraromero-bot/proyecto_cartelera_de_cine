CARTELERA DE CINE
Este proyecto consiste en el desarrollo de un sistema de cartelera de cine en Python que permite administrar usuarios, películas y snacks mediante operaciones CRUD. El sistema cuenta con dos tipos de acceso: administrador y usuario. El administrador puede registrar, mostrar, buscar, modificar y eliminar información, mientras que el usuario puede consultar la cartelera, visualizar snacks, revisar precios, comprar entradas y generar facturas. Para su desarrollo se aplican conceptos aprendidos durante el segundo semestre, como funciones, modularización, listas, estructuras condicionales, manejo de errores con try except, ciclos y uso de match case.
